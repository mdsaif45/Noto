# Spikes

Throwaway prototypes that answer a technical question. **Not production code.**

A spike is deleted or superseded once its question is answered and the answer is
recorded in `docs/architecture/spikes/`. Nothing here is referenced by
`src/`, and nothing here is held to production standards.

| Spike | Question | Issue | Result |
| ----- | -------- | ----- | ------ |
| `WindowBehaviour` | Can WinUI 3 + Windows App SDK deliver Noto's window model? | [#2](https://github.com/mdsaif45/Noto/issues/2) | See [the write-up](../docs/architecture/spikes/window-behaviour.md) |
| `HiddenMarkdown` | Can a `RichEditBox` hide markdown's markup while its text stays the source, within budget? | Phase C design gate (P2.0) | See [the write-up](../docs/architecture/spikes/hidden-markdown.md) and [ADR-017](../docs/decisions/ADR-017-editor-model.md) |
